# Support shoka's automotive open source

I build open-source tools for exploring vehicle diagnostics and automotive AI workflows.

## Projects you can support

- [obd2-mcp](https://github.com/shoka-jp/obd2-mcp): an MCP server for OBD-II data, with a mock vehicle for trying it without hardware.
- [automotive-ai-skills](https://github.com/shoka-jp/automotive-ai-skills): 16 skills covering diagnostics, maintenance, used-car inspection, and more, with English and Japanese documentation.

Sponsorship supports my work on these open-source projects: code maintenance, clearer setup instructions, examples, and documentation. Current planned features are listed in each repository's roadmap; sponsorship does not promise a particular delivery date.

[**Sponsor shoka on GitHub**](https://github.com/sponsors/shoka-jp)

You can also help by trying the projects, reporting reproducible problems, improving translations, and sharing useful examples. Follow [shoka-jp](https://github.com/shoka-jp) to find my work.
